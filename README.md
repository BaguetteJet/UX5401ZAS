# Kubuntu and Windows UX5401ZAS

Dual booting Kubuntu 26.04 and Windows 11 on the Asus Zenbook 14X OLED Space Edition UX5401ZAS.

## Introduction

I successfully installed Kubuntu, keeping Windows BitLocker and Secure Boot on. I used LUKS2 encryption for the root Linux partiton and manually repaired the GRUB boot configuration/installation after a failed installation.

But why install Linux when Windows works OK? 

The Windows Subsystem for Linux 2 (WSL 2) is enough to complete my course work. I was annoyed with the short laptop battery life and decided to experiment with Linux after updating the BIOS. I had to update the BIOS to resolve an issue where laptop took 2-3mins to power on.
